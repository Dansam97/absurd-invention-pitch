A make.fun entry for **One-Sentence Absurd Invention Pitch**: one sentence pitching a ridiculous invention that fixes a tiny everyday annoyance. This entry pitches the Amnesia Doorframe, which eavesdrops on your muttering all day and whispers your errand back when you walk into a room and forget why you came. Running the program writes the pitch to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
